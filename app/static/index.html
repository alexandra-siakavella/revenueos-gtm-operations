Integration principles

Guardrails for maintainable automations.

1
Make writes idempotent
Retrying a request must not create duplicate records or actions.
2
Observe every critical flow
Log outcomes, surface failures, and assign an owner.
3
Validate before write-back
Schema checks and human approval for sensitive CRM changes.
4
Keep credentials out of code
Use environment variables or a secrets manager.
